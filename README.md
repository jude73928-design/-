# Arabic Study Pal

"Create a dark-themed Flashcards web app using React and Tailwind CSS. The UI should have a deep navy background with purple accents. Key features: a text area for pasting long Arabic/English content, a slider to set max words per card, and a spaced repetition study mode. Include a TTS (Text-to-Speech) feature with adjustable WPM speed, keyboard shortcuts (1-4 for grading, Space to play), and a progress bar. The grading buttons should be color-coded: Red (Hard), Orange (Struggled), Green (Good), and Blue (Easy). Save progress to local storage."
